# 更新日志

> [!NOTE]
> 自 1.2.0 之后，更新日志将按时间从新到旧排序各版本的内容，方便快速预览近期修改。

## v1.3.0 · 安全增强

- 🛡修复了账号登录系统存在的一些问题
- 💬初步支持 GitHub alerts 标注块，详见[《可视化编辑指南》](/doclight-default/doclight-default-guide)。
- 📝支持对页面进行手动排序，可以在空间页面或侧边栏拖动手柄调整
- 👀其他底层稳定性改进

## v1.2.0 · 持续打磨

- 🔒 支持锁定空间，二次修改需鉴权
- 🌟 引导文档只能由源码修改，便于随版本同步
- 📂 支持挂载到网站子目录，管理更方便
- 🐛 Bug 修复：运行更稳定

## v1.1.0 · 体验改进

- 🖊 Markdown/可视化编辑器：修改更自由
- 🛡 备案号悬挂：网站合规运行
- 🐛 Bug 修复：运行更稳定

## v1.0.0 · 首发

- 🎉 可视化编辑器：标题、文本样式、列表、引用、代码块、链接与图片
- 🌗 深浅色主题：跟随系统 + 手动三态切换，偏好本地记忆
- 📄 页面管理：新建、重命名、删除、侧栏搜索
- 🛡 渲染前内容净化，拦截脚本注入
- 🔌 TypeScript 构建，空闲端口自动探测
