# 欢迎使用 [DocLight](https://github.com/Mooling0602/DocLight) ✦

这是一个**轻量的可视化文档站**：浏览器里直接排版，保存即刻生效。TypeScript 源码、浏览器单页应用与数据文件都在同一项目中。

> 设计理念 —— 简洁优雅、开箱即用；写作本身不该比写下的内容更费劲。

## 它有什么

- **双模式编辑**：所见即所得工具栏，标题、粗斜体、列表、引用、代码块一应俱全，切换 Markdown 模式也可以使用更多标记语法
- **深浅色适配**：自动跟随系统外观，也可手动切换并记住选择
- **TypeScript 构建**：首次执行 `npm install`，再用 `npm start` 编译并启动
- **自动找端口**：端口被占用时自动探测下一个空闲端口

## 首次使用：先有账号与自己的空间

1. **初始化账号**：点左上角「DocLight」回到空间总览，右上角会显示「初始化账号」（阅读页顶栏为节省空间会隐藏它）。用户名限字母、数字、下划线、连字符（≤40 位），密码至少 6 位、只能用英文、数字与半角符号。密码经 PBKDF2 派生后只存派生值，明文不落盘；登录状态保持 7 天并自动续期。初始化成功后会自动登录，按钮变成「退出」。
2. **新建一个普通空间**：点侧栏顶部的「新建空间」，或空间总览右上角的「＋ 新建空间」，输入名称即可。空间是一组文档的容器，可以按产品手册、团队博客等再分。
3. **在新空间里新建页面**：进入空间后点「＋ 新建页面」，或把鼠标移到侧栏的空间名上点「＋」；页面行上的「＋」则会新建它的子页面，用来搭目录层级。

> [!NOTE]
> 内置空间 `doclight-default`（也就是本页所在的「DocLight 介绍」）的内容来自应用源码，随版本一起更新，**永久只读**：不显示「编辑」按钮，也没有新建页面、删除等入口。想动手改内容，请按上面的步骤建自己的空间与页面。

## 开始写作

1. 打开页面，点右上角 **编辑**（未登录时会先弹出登录框）；
2. 像使用字处理软件一样直接排版，也可以切换到 Markdown 模式编辑语法标记；
3. 按 `Ctrl / ⌘ + S` 或点击 **保存** 即可发布；「取消」会放弃本次修改，若已有改动会先向你确认。

## 常用快捷键

- `Ctrl / ⌘ + S` —— 保存（只在编辑状态下生效）
- `Ctrl / ⌘ + B` / `I` / `U` —— 粗体 / 斜体 / 下划线
- `Ctrl / ⌘ + Z` —— 撤销，`Ctrl / ⌘ + ⇧ + Z` —— 重做
- `Tab` / `Shift+Tab` —— 增减缩进：可视化模式作用于列表与引用块，代码块内 `Tab` 插入 4 个空格，Markdown 模式按行处理
- `Esc` —— 优先关闭弹窗、菜单或侧栏抽屉；否则退出编辑，有未保存的修改时会先确认

## 顺手的功能

- **侧栏搜索**：顶部搜索框按标题筛选，底部显示「匹配 N 页」；
- **排序**：空间索引页或「空间设置」里可切换排序方式；拖动侧栏每行左侧的握把调整同级顺序；顺序实际变化并保存后，空间会自动切到「手动排序」；
- **复制链接**：正文上方的「复制页面链接」复制整页地址，鼠标移到二级或三级标题上点链接图标则复制该小节（`#h-数字`）的地址；
- **深浅色**：右上角切换「跟随系统 / 浅色 / 深色」，选择会被记住；
- **上一篇 / 下一篇**：空间设置里开启「自动按顺序推荐其他文章」后，文章底部会显示相邻文章卡片；
- **调整正文宽度**：阅读页右边缘有拖动手柄，双击恢复默认（窄屏或不支持悬停的设备上自动隐藏）。

## 样式一览

行内代码长这样：`npm run build`；代码块支持多行：

```
// 首次运行先安装依赖
npm install
npm start
// → http://localhost:4173
```

准备好了？去看看[《可视化编辑指南》](/doclight-default/doclight-default-guide)吧。
