# 可视化编辑指南

DocLight 的编辑器是「所见即所得」的——你排版的样子，就是读者看到的样子。

注意：编辑模式下，分割线上方的标题仅用于标记，不会渲染成实际的文章标题，请在其下方首行或者其他位置手动添加文章标题。

## 进入与退出

- **编辑**：可编辑页面右上角点击「编辑」；首次编辑需要先登录，未登录时会先弹出登录框；
- **保存**：顶栏右侧的「保存」按钮，或快捷键 `Ctrl / ⌘ + S`（编辑中随时可用）；
- **取消**：放弃本次修改；若有未保存改动会先向你确认。

> 内置空间 `doclight-default` 的内容来自应用源码，页面上不显示「编辑」按钮，只能阅读。要练习排版，请先在「新建空间」里建一个普通空间。

## 工具栏说明

### 段落样式

H1 / H2 / H3 将选中的段落转换为各级标题，「¶」恢复为普通段落。

### 文字样式

**粗体**、*斜体*、<u>下划线</u>、~~删除线~~，以及行内代码 `like_this()`。

### 列表与引用

- 无序 / 有序列表，`Tab` 增加缩进，`Shift+Tab` 减少。

> 这就是引用块的效果，适合放提示或强调。

### 标注块

引用块首行写 `> [!NOTE]`，就会渲染成 GitHub alerts 风格的标注块，支持 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 五种类型（渲染后的标题依次为注意、提示、重要、警告、危险）；框内每行保持 `>` 前缀即可：

> [!NOTE]
> 适合补充说明，读者略读时也不会错过。

> [!TIP]
> 写一些技巧提示，实操可以更进一步。

> [!IMPORTANT]
> 强调注意事项，避免犯错。

> [!WARNING]
> 提醒潜在的坑，动手之前先看一眼。

> [!CAUTION]
> 发出严重警告，引起高度重视。

标记必须独占首行（后面只能有空白），写成 `> [!NOTE] 补充说明` 会退化为普通引用；类型不区分大小写，经可视化编辑回写后统一为大写。

标注块暂时还不支持可视化编辑，请切换至 Markdown 模式进行修改；已存在的标注块在可视化模式里改正文，保存后标记仍会保留。

### 对齐方式

居左 / 居中 / 居右，作用于光标所在段落；清除格式会一并重置对齐。

### 插入元素

- **链接**：选中文字后点击，输入地址即可；外部链接自动在新标签页打开；
- **图片**：填写图片地址（支持 http(s)、data:image 与 `/` 开头的站内路径），宽度自适应容器；
- **代码块 / 分隔线**：让版面更有层次。

## 视觉模式与 Markdown 模式

进入编辑后，顶栏右侧会变成「可视化 / Markdown」切换与保存按钮：

- **可视化**：带工具栏的所见即所得编辑，粘贴网页内容时会自动清理掉多余的标签与样式；
- **Markdown**：直接编辑源码，标注块的 `[!NOTE]` 标记只能在这里写；此模式下工具栏会隐藏。

两种模式描述的是同一份文档，切换时当前内容会先转成 Markdown 再交给另一侧，因此可以随时来回切换而不会丢内容。

## 常用快捷键

- `Ctrl / ⌘ + S` —— 保存（只在编辑状态下生效）
- `Ctrl / ⌘ + B` / `I` / `U` —— 粗体 / 斜体 / 下划线
- `Ctrl / ⌘ + Z` —— 撤销；`Ctrl / ⌘ + ⇧ + Z` —— 重做
- `Tab` / `Shift+Tab` —— 列表与引用块中增减缩进，代码块内 `Tab` 插入 4 个空格；Markdown 模式按行缩进 2 个空格，`Shift+Tab` 退回
- `Esc` —— 优先关闭弹窗、菜单或侧栏抽屉；否则退出编辑，有未保存的修改时会先确认

> 浏览页面时也有快捷操作：鼠标悬停二级或三级标题，右侧会出现链接图标，点击即可复制该小节（`#h-数字`）的地址。

## 页面路径（slug）

每个页面创建时会按标题自动生成路径，中文标题会退化为随机字符串，例如 `/my_space/a1b2c3d`。路径只允许小写字母、数字与下划线（1–80 位），且不能与已有空间或页面重名。

- **改标题不会改路径**：重命名标题只更新显示名，链接地址保持不变；
- **改路径会换地址**：点击正文上方那行元信息里的 `#路径` 标签，或页面右上角「⋯」菜单中的「编辑路径…」，即可改写；保存后旧链接立即失效，需要重新分发新地址；
- 子页面的路径同时决定它的层级地址（`/空间/父页面/子页面`），父级路径变化时，Markdown 中硬编码的旧链接也需要手动更新；
- 空间路径同样可以改：侧栏空间名旁的「⋯」→「空间设置…」→「编辑路径…」，规则与页面一致，改完后该空间下所有页面的链接都会变化。

## 其他上手功能

- **复制页面链接**：正文上方的「复制页面链接」直接写入剪贴板；
- **调整正文宽度**：阅读页右侧边缘有拖动手柄，拖动可加宽/收窄正文，双击恢复默认；窗口宽度不超过 900px 或设备不支持悬停时该手柄会自动隐藏；
- **查看子页面卡片**：在空间索引中点击卡片上的「查看子页面」，进入该页面的子页面列表；可继续逐层查看，通过面包屑或浏览器前进、后退返回；
- **侧栏搜索**：侧栏顶部搜索框按标题筛选，底部显示「匹配 N 页」；
- **排序与手动拖动**：空间索引页或空间设置里可切换「最新创建在前 / 最早创建在前 / 最近编辑在前 / 最久未编辑在前 / 标题顺序 / 手动排序」；拖动卡片或侧栏每行的握把可调整同级顺序，顺序实际变化并保存后，该空间会自动切到「手动排序」；
- **深浅色**：右上角切换「跟随系统 / 浅色 / 深色」，选择会被记住；
- **上一篇 / 下一篇**：空间设置里开启「自动按顺序推荐其他文章」后，文章底部会出现相邻文章卡片。
