# 可视化编辑指南

DocLight 的编辑器是「所见即所得」的——你排版的样子，就是读者看到的样子。

注意：编辑模式下，分割线上方的标题仅用于标记，不会渲染成实际的文章标题，请在其下方首行或者其他位置手动添加文章标题。

## 进入与退出

- **编辑**：任意页面右上角点击「编辑」；
- **保存**：工具栏右侧按钮，或快捷键 `Ctrl / ⌘ + S`；
- **取消**：放弃本次修改；若有未保存改动会先向你确认。

## 工具栏说明

### 段落样式

H1 / H2 / H3 将选中的段落转换为各级标题，「¶」恢复为普通段落。

### 文字样式

**粗体**、*斜体*、<u>下划线</u>、~~删除线~~，以及行内代码 `like_this()`。

### 列表与引用

- 无序 / 有序列表，`Tab` 增加缩进，`Shift+Tab` 减少。

> 这就是引用块的效果，适合放提示或强调。

### 标注块

引用块首行写 `> [!NOTE]`，就会渲染成 GitHub alerts 风格的标注块，支持 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 五种类型；框内每行保持 `>` 前缀即可：

> [!NOTE]
> 适合补充说明，读者略读时也不会错过。

> [!TIP]
> 写一些技巧提示，实操可以更进一步。

> [!IMPORTANT]
> 强调注意事项，避免犯错。

> [!WARNING]
> 提醒潜在的坑，动手之前先看一眼。

> [!CAUTION]
> 发出严重警告，引起高度重视。

标注块暂时还不支持可视化编辑，请切换至 Markdown 模式进行修改。

### 对齐方式

居左 / 居中 / 居右，作用于光标所在段落；清除格式会一并重置对齐。

### 插入元素

- **链接**：选中文字后点击，输入地址即可；外部链接自动在新标签页打开；
- **图片**：粘贴图片 URL，宽度自适应容器；
- **代码块 / 分隔线**：让版面更有层次。

## 常用快捷键

- `Ctrl / ⌘ + S` —— 保存
- `Ctrl / ⌘ + B` / `I` / `U` —— 粗体 / 斜体 / 下划线
- `Ctrl / ⌘ + Z` —— 撤销

## 关于 slug

每个页面在创建时生成唯一的 slug 并永久绑定到链接，之后重命名标题也不会失效。
